## ✨ What is Soc Ops?

**Soc Ops** (Social Operations) is an interactive social bingo game designed to turn awkward mixers into engaging icebreakers. Whether you're at a company event, meetup, or conference, this game encourages meaningful conversations and helps people discover unexpected connections.

### 🎯 How It Works

1. **Get Your Card** - Receive a unique 5×5 bingo card with fun conversation starters
2. **Mingle & Match** - Walk around and find people who match each square's description
3. **Mark It Off** - Tap squares as you discover matches
4. **Win!** - Get 5 in a row (horizontal, vertical, or diagonal) to win
5. **Celebrate** - Show off your winning card and the connections you made!

## 🌟 Features

- 🎲 **Randomized Cards** - Every player gets a unique bingo card
- 📱 **Mobile-First Design** - Works seamlessly on phones and tablets
- 💾 **Auto-Save Progress** - Game state persists even if you close the browser
- 🎨 **Modern UI** - Built with React 19 and Tailwind CSS v4
- 🚀 **Lightning Fast** - Powered by Vite for instant load times
- ♿ **Accessible** - Designed with accessibility in mind
- 🎯 **Free Space** - Center square is always marked to get you started

## 🚀 Quick Start

### Prerequisites

- [Node.js 22](https://nodejs.org/) or higher

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/srvchawla/my-bingo-app.git
cd my-bingo-app

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to see the app in action! 🎉

### Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist/` directory.

## 🎮 How to Play

### For Players

1. **Open the app** on your mobile device or laptop
2. **Tap "Start Game"** to generate your unique bingo card
3. **Walk around** and strike up conversations
4. **Find matches** - When someone fits a square's description, tap it!
5. **Get 5 in a row** to win - the app will celebrate with you! 🎊
6. **Keep playing** - You can continue filling squares or reset for a new game

### For Organizers

Host a successful Social Bingo event:

1. **Share the link** - Send `https://srvchawla.github.io/my-bingo-app/` to all attendees
2. **Set a time limit** - Give players 15-30 minutes to mingle
3. **Offer prizes** - First person to get bingo wins!
4. **Encourage interaction** - Remind players to actually talk, not just tap squares
5. **Multiple rounds** - Reset and play again with different prompts

## 🎨 Customization

Want to customize the questions for your event? Edit the prompts in:

```typescript
src/data/questions.ts
```

Each question should be short and conversational. Examples:
- "has lived in another country"
- "speaks more than 2 languages"
- "loves cooking"

👉 **Workshop participants**: [Follow the Lab Guide](.lab/GUIDE.md) for detailed customization instructions.
