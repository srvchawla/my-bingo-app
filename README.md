## 🌟 What is Soc Ops?

Soc Ops is an interactive social bingo game that transforms in-person events from awkward small talk into meaningful conversations. Instead of traditional bingo numbers, players hunt for people who match fun, engaging prompts on their bingo card.

## ✨ Features

- 🎲 **Dynamic 5×5 Bingo Grid** – Each square contains a conversation starter
- 🎯 **Free Center Space** – Start with a head start
- ✅ **Interactive Gameplay** – Tap squares as you find matches
- 🏆 **Win Detection** – Automatic detection of horizontal, vertical, and diagonal wins
- 📱 **Mobile Friendly** – Works seamlessly on phones, tablets, and desktops
- 💾 **Progress Saved** – Your game state persists across sessions
- 🎨 **Modern UI** – Clean, accessible design built with React 19 and Tailwind CSS v4

## 🎮 How to Play

1. **Meet Someone New** – Start a conversation with someone at your event
2. **Find a Match** – Discover if they match any of the prompts on your card
3. **Mark Your Square** – Tap the square when you find a match
4. **Get 5 in a Row** – Complete a horizontal, vertical, or diagonal line
5. **Celebrate!** – Show off your BINGO and share your stories

## 🚀 Quick Start

### Prerequisites

- [Node.js 22](https://nodejs.org/) or higher

### Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to see the app in action! 🎉

### Build for Production

```bash
npm run build
```

The app deploys automatically to GitHub Pages on every push to `main`.
